# BE YOU · Create Your Life
Web de la comunidad de apoyo BE YOU. HTML/CSS/JS vanilla, sin build ni npm. GitHub Pages.

- Local: `python3 -m http.server` en la raíz.
- Formulario de contacto: `assets/config.js` → `CORREO_CONTACTO` (vacío = aún no conectado).
- Pendiente de la fundadora: página «Quién soy», datos de privacidad y aviso legal, fechas, lugar y precios, foto.
- Todas las páginas llevan `noindex` hasta el lanzamiento.
